# Applied Artificial Intelligence (AAI)

This repository contains the course materials for **Applied Artificial Intelligence (AAI)**. It includes the Python introduction, exercises, solutions, and project-related material used throughout the course.

## Material release schedule

Course materials will be uploaded gradually during the semester.

- The exercise for each discussion/exercise session will be uploaded **at least one week before the corresponding session**.
- The respective solutions will be uploaded **after the corresponding discussion/exercise session**.

Please check the repository regularly for newly released exercises, solutions, and possible updates to existing material.

## Shared datasets

All local datasets and download caches are stored once in the repository-level [`data`](data/) directory.

The notebooks locate the directory automatically when Jupyter is started from the repository root or from an individual exercise directory.

## Keeping exercise materials up to date

All exercises are subject to change. Students should therefore pull the latest version of the repository shortly before starting each exercise. If you are not using Git, download the current ZIP archive again instead.
